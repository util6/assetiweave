# 分诊标签

工程技能使用五个标准分诊角色。本文件将这些角色映射到本仓库问题追踪器中的实际标签。

| 技能中的标准角色 | 追踪器标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估的问题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由 AFK Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

技能提及某个分诊角色时，使用本表右侧的实际标签。若仓库标签体系变化，更新“追踪器标签”列即可。
